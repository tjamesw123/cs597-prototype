# CS 597 Prototype

# Launching the Prototype

- Clone the repo onto your computer with 'git clone https://github.com/tjamesw123/cs597-prototype/'

- Make sure you have npm installed onto your machine and run 'npm i' when in the cloned repository to install dependencies

- Then run 'npm run dev' to start the project

- Default logins are dana@example.com and maya@example.com with the passwords both being 1234, Dana being the employer and Maya being the applicant, both of them have sample data to be viewed.
